# gzh-design-skill · 石墨极简深色变体

补进 `references/theme-graphite-minimal.md` 的「设计变量速查表」之后。上游是公众号浅色单主题，没有深色定义。

## 适用范围

`assets/theme-previews/`、`docs/gallery/` 等独立预览页，以及主题被复用到网页、文档等非公众号载体时。

**不适用于公众号正文产物。** 微信自行处理深色反色，`@media` 会被剥离，文章无法自带深色板。写进组件 HTML 等于无效代码，也会被上游的 `component_lint.py` 判 ERROR（它禁 `@media` 和 CSS 变量）。

## 值

```
主色（石墨灰）：   #A1A1AA（正文色 / 下划线专用）
标题色（浅炭）：   #FAFAFA
浅灰强调：         #E4E4E7
辅助文字色：       #6B6B73（署名 / 说明 / 编号小字）
次要文字色：       #8B8B93
极细线色：         #2C2C31（分割线 / 边框 / 大号水印编号）
标签底色：         #27272A（关键词标签底）
极浅灰底：         #1B1B1F（引用块 / 目录卡 / 提示块）
卡片底：           #18181B（对应浅色的纯白底）
正文底：           #121214
强调色（暖橙）：   #FB923C（全篇 ≤3 处，仅用于锚点点睛）
```

## 推导规则

整组沿 Zinc 色阶镜像，浅色取低阶则深色取对应高阶（`zinc-600 → zinc-400`、`zinc-800 → zinc-50`、`zinc-200 → zinc-800/900 之间`）。

橙色不镜像，改用 `orange-400`，因为 `orange-500` 在深底上明度不足、与正文灰拉不开。

字号、行高、字间距、宽度、间距体系全部沿用浅色，不随明暗切换变化。
